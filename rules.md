# Rules and Styling System - AutoMarketer AI

## Styling System Specs (Neo-Brutalist Web Design)
- **Borders**: 3px or 4px solid black strokes (`border-4 border-black`).
- **Shadows**: Flat 2D projections (`shadow-[6px_6px_0px_0px_rgba(0,0,0,1)]`).
- **Fills / Palettes**:
  - Background: Off-white `#F4F0EA`
  - Yellow: `#FFE600` (Electric Yellow)
  - Green: `#00FF9D` (Mint Green)
  - Orange: `#FF5C00` (Hot Orange)
  - Purple/Lavender: `#E2D4FF` (Retro Lavender)
  - Blue: `#70A5FF` (Retro Blue)
- **Typography**: Anton condensed uppercase headings, Space Mono labels, Archivo Narrow body.
- **Interactions**: Button translate shifts down-right on active (`active:translate-x-1 active:translate-y-1 active:shadow-none`).
